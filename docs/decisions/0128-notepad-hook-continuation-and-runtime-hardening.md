# ADR-0128: Notepad 影子入口透明继续执行与运行时初始化加固
- **状态**: 已采纳
- **日期**: 2026-10-29
- **上下文与痛点**: 调试 Notepad 入口补丁固定覆盖 24 字节并覆盖原始 RCX，X1 返回时没有回到被覆盖指令之后；入口长度可能截断指令，Shellcode 槽位初始化在并发调用下存在竞态，动态导出解析和失败清理也缺少边界与释放闭环。
- **技术决策与规范**: 使用 HDE64 按指令边界解码 12 至 64 字节入口；补丁只设置 `mov rax, ShellcodeEntryVa; jmp rax`，X1 保存/恢复 RCX、RFLAGS 和非易失寄存器，并跳转到 `HookVa + PatchSize`。运行时镜像增加 Resume immediate，由驱动在 `.text` 中补丁化；RuntimeSlot 增加 0/1/2/3 原子初始化状态；模块导出解析加入 DOS/NT/导出表基本校验，Unicode 模块哈希按 WCHAR 数量计算；初始化失败路径释放已分配上下文；Machenike 工程编译 `hde64.c`。
- **已知约束与避坑**: 入口补丁不得跨页；HDE 解码失败或读取不足时拒绝安装；继续地址必须在同一目标入口页之后且无整数回绕；Shellcode 调用前遵循 x64 影子空间和 16 字节对齐；清理采用状态门控并先恢复影子入口再移除 Hook/视图和释放目标页；不在本机加载驱动。
