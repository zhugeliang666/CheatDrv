# ADR-0181：X2 深度模式崩溃隔离门禁
- **状态**：已采纳（运行时复测待完成）
- **日期**：2026-11-03
- **上下文**：x64dbg 观察到 X2 日志曾执行，但随后主线程 `RIP=0x0`、调用栈为空；寄存器仍指向副槽数据区，说明副钩子内的嵌套伪造调用可能覆盖或失效化返回上下文。
- **决策**：当 `VT_SHELLCODE_DEEP_UNWIND=1` 时，`CustomHookDispatch2` 仅完成副槽初始化并返回，不在 X2 中执行 `DbgPrintW`、`VirtualQuery` 或其他嵌套 `SpoofCall`；X1 主路径及原始指令恢复路径不变。浅层模式保留原诊断逻辑。
- **验收**：DebugShellcode 与 Machenike 均需成功构建；重新加载驱动和新建目标进程后，确认 X2 不再把主线程带到 `RIP=0`，再单独恢复深度日志调用。
