# ADR-0178: X1 深层私有栈返回前回写原生保存帧
- **状态**: 已采纳
- **日期**: 2026-11-01
- **上下文与痛点**: X1 深层模式将入口保存区复制到 data 页私有栈，RuntimeDispatch 返回后原实现直接从私有保存区恢复寄存器并跳回 ResumeVa，导致 RSP 停留在 `PrivateStackTop`。原始函数随后在 data 页继续建立栈帧，最终可能破坏运行时上下文并以 `RIP=0` 触发 `0xC0000005`。
- **技术决策与规范**: X1 私有栈路径在公共恢复序列前，将 `0x31` 个 QWORD 从私有保存区回写到 `OriginalRsp - 0x180` 的原生保存区，再以 `OriginalRsp - 0x20` 进入公共 `add rsp,20h` 恢复路径。X2 已有同等“私有区回写原生区”语义，保持两条入口的恢复模型一致；`0x31` 复制长度继续覆盖入口返回地址槽。
- **已知约束与避坑**: `r15` 在 RuntimeDispatch 返回后继续作为 RuntimeSlot 指针使用，回写循环只能使用 `r13/r14/rax/ecx` 作为临时寄存器；回写完成后必须将 RSP 设置为保存区起点减 `0x20`，否则公共清理会再次错位。变更已通过 DebugShellcode 与 Machenike x64 Debug 构建、签名及静态回滚验证；Notepad 运行时复测仍需在受控调试环境完成。
