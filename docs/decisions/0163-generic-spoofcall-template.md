# ADR-0163: `SpoofCall` 改为四参数通用类型模板

- **状态**: 已采纳
- **日期**: 2026-10-31
- **上下文与痛点**: 原始汇编入口声明绑定 `MessageBoxW` 的具体参数类型和 `int` 返回值，虽然调用点名称已统一为 `SpoofCall`，但无法安全复用到其它四参数标量/指针函数。
- **技术决策与规范**: 保留三个汇编符号作为原始 ABI 入口，C++ 层改为 C++14 兼容的 `SpoofCall<TTarget,TArg0,TArg1,TArg2,TArg3>` 模板；模板负责目标地址写入、指针/整数/枚举参数打包、Native/Ghost/Deep 入口选择及标量/指针/`void` 返回值还原。汇编入口第 4 个参数从 `r9d` 扩展为读取完整 64 位槽位 `r9`。
- **已知约束与避坑**: 仅支持四个标量或指针参数及标量/指针/`void` 返回值；不支持浮点、聚合体、变参或第 5 个以上参数；目标必须是函数指针且先通过非空/地址门禁；RuntimeSlot、SPOOF_CALL_CONTEXT 和深层栈布局保持不变。
