# ADR-0146: Stolen Bytes 拒绝 RIP 相对与相对分支指令
- **状态**: 已采纳
- **日期**: 2026-10-30
- **上下文与痛点**: Notepad 调试 Hook 将入口覆盖的完整指令复制到独立代码区回放。若回放区含 RIP 相对寻址或相对分支，搬移后 RIP 改变会使目标地址失真。
- **技术决策与规范**: `VtDecodeHookPatchSize` 在 HDE64 指令边界解码后检查 `F_RELATIVE`；命中即记录诊断并拒绝生成 stolen-byte span，不执行未经重定位的复制。后续若要支持此类指令，必须增加经过验证的位移重定位路径，而不是放宽当前门禁。
- **已知约束与避坑**: 当前实现是 fail-closed；入口补丁失败时不得安装 Hook。该门禁不改变 R3 Gadget 缓存，也不扩展堆栈伪造调用面。修改后须重新构建并刷新嵌入 Shellcode 产物。
