# ADR-0151: 方案1 X1 入口占位地址误解引用修复
- **状态**: 已采纳
- **日期**: 2026-10-30
- **上下文与痛点**: Notepad Hook 安装成功后立即用户态崩溃。方案1运行时补丁器只替换 `49 BB imm64`（`mov r11, imm64`）形式的 RuntimeSlot 占位符；此前为方案3新增的 X1 首部 `mov rax, 1122334455667788h` 不属于该补丁模式，导致首次 Hook 进入时使用占位地址读取 `+0x34`。
- **技术决策与规范**: 删除未被补丁器识别的 X1 首部占位访问；统一使用已由 `VtEmbeddedPatchRuntime` 替换的 `mov r11, 1122334455667788h`。方案1直接沿用参考提交的原生栈路径；方案3在保存区完成后用 `lea rax, [rsp+178h]` 计算 Hook 入口原生 RSP，再写入 `RuntimeSlot::OriginalRsp(+0x18)`。嵌入镜像必须在汇编变更后重新生成。
- **已知约束与避坑**: RuntimeSlot 补丁模式当前只覆盖 `49 BB`；新增地址占位符必须同步扩展扫描/补丁逻辑，否则禁止在入口解引用。方案1必须保持 `OriginalRsp==0`，不得进入私有栈恢复分支。本修复已完成 Debug|x64 候选/真实构建、签名和独立副本回滚验证；目标机重新加载后的 Notepad 实测待执行。
