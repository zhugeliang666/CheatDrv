# ADR-0005: 传输层通信架构重构与性能可靠性加固 (TCP / UDP / USB)
- **状态**: 已采纳
- **日期**: 2026-10-11
- **上下文与痛点**:
  - **TCP (WSK)**: 在高频内存读写 RPC 场景下，每次收发均调用 `IoAllocateIrp` 与 `IoFreeIrp`，频繁冲击系统 I/O 管理器 Lookaside 链表与大内存池，产生剧烈 CPU 开销与锁竞争；同时在每次处理完一帧后执行 256KB 缓冲区的 `memmove`，导致 L1/L2 缓存严重抖动；服务端退出时未主动中断已连接 Socket 的等待，存在卸载死等隐患。
  - **UDP (WSK)**: 单包 64KB 远超网络 MTU (1500 字节)，在 IP 层被强制拆分成 40~50 个 IP 分片，只要一个分片丢包整个 64KB 数据报即被网络栈丢弃，导致大内存扫描频繁超时中断；且退出状态机中硬编码 `STATUS_PENDING` 导致同步时序隐患。
  - **USB (WinUSB / USBHUB3)**: 1MB 单包串行等待无法填满 USB 3.0 控制器的硬件 DMA FIFO，吞吐受限；同步挂起等待在特定 xHCI 控制器上停止时易产生挂起。
- **技术决策与规范**:
  1. **TCP 常驻 IRP 与游标缓冲**:
     - 在每个客户端上下文 `MK_WSK_CLIENT` 中预分配常驻同步 `PIRP pRecvIrp` 和 `PIRP pSendIrp`，通过 `IoReuseIrp` 循环重用，彻底消除热路径上的系统 I/O 分配调用。
     - 优化接收缓冲区滑动逻辑：引入游标指针滑动，仅在未读数据跨越尾部边界时才触发整理，大幅减少内存拷贝。
     - 增强 `WskServer_Stop`：主动下发中止与清理，保证工作线程秒级退出。
  2. **UDP 分片重组协议与可靠通道 (MTU-Friendly Chunking)**:
     - 引入 MTU 友好型分片头，单分片净荷限制在 1400 字节以内，彻底解决以太网 IP 分片雪崩丢包。
     - 消除重复的 IRP 分配，修复 `WskCloseSocket` 状态机判断。
  3. **USB 通道流水线与安全退出加固**:
     - 保证严格遵循 `cheatdrv` 铁律，不入线程链表，利用非阻塞轮询与超时监控保护，确保优雅退出。
- **已知约束与避坑**:
  - 严禁对常驻 IRP 重入调用；每次重用必须通过 `IoReuseIrp(Irp, STATUS_SUCCESS)` 重置栈指针并重新挂接完成例程。
  - 线程退出前必须确保常驻 IRP 处于未决状态之外（Completed 状态）方可 `IoFreeIrp`。
